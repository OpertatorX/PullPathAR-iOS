Measure the actual path

Place route points with ARKit along walls, ceilings and transitions. PullPath derives a 3D route profile with horizontal travel, vertical travel and elevation range. A manual workflow remains available when AR is not suitable.

Plan the pull

Apply fixed slack and percentage allowance, attach a cable profile, then compare the required length with active reels before committing to the pull.

Leave a usable record

Add site photos, edit route points, track status and history, and export a PDF pull sheet with segment lengths, cable requirement and reel information.

Built for the installer holding the phone.

PullPath AR is intentionally focused on one field workflow: turning a physical cable path into a documented, material-aware route. It is not a generic project-management dashboard and it does not require a cloud account to work.

FR — Mesurez le chemin réel, préparez le tirage.
